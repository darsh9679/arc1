# Patwardhan House images

Architecture / Residential house with a built-up area of 3,000 sq. ft.

The current gallery contains 15 supplied architectural visualizations. All
original filenames and image bytes are retained, including one repeated export.
metadata.json supplies readable captions and alt descriptions. The first file
becomes the project cover.

Add JPG, JPEG, PNG, WebP or AVIF files directly in gallery/, update matching
metadata entries, then run npm run images:sync and refresh the website. A
deployed site needs a rebuild/redeploy. See docs/PROJECT-IMAGES.md.

This project is currently marked visualizationOnly in lib/content.ts so the
cover, gallery and full-screen viewer do not describe renders as photographs.
Change that setting if the collection is later replaced with actual photography.
